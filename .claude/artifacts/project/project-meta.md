## Notes
- Successor to `quick-web-notepad`, which had no persistence at all: a refresh or
  a closed tab lost everything. That gap is the reason this project exists.
- Two documentation homes are in use by explicit decision. The superpowers design
  spec is canonical; these artifacts elaborate on it. When they disagree, the spec wins.
- Part of the OFCode "Quick" family.
