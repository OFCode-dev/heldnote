Questions

Do I need an account to use Heldnote?
No. There is no sign-up, no email and no login. Heldnote has no user accounts because it has no server to hold them — open the page and start writing.
Where are my notes stored?
In your own browser, in its IndexedDB storage, on the device you are using. Nothing is uploaded. Because that storage belongs to one browser on one device, notes do not appear in another browser unless you move them there with a backup file or a Google Drive backup you control.
What does version history keep?
Heldnote checkpoints a note as you write and keeps those earlier versions alongside the current text. Any version can be previewed and restored without discarding what you have now. Older versions are trimmed when browser storage runs low, and the status bar says when that happens rather than hiding it.
Can I write ASCII diagrams and tables in Heldnote?
Yes. The writing surface uses a serif face by default for reading prose, and the editor toolbar has a monospace toggle for notes where column alignment matters — ASCII and Unicode box-drawing diagrams, tables, code and log excerpts. The setting is remembered across sessions.
Is Heldnote free and open source?
Yes, free with no paid tier, and the source is public on GitHub. It ships as plain HTML, CSS and JavaScript modules with no framework, no build step, no analytics and no third-party requests at runtime.
