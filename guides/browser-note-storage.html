A HELDNOTE FIELD GUIDE

Where does an online notepad save your notes?

Heldnote saves notes in this browser’s IndexedDB storage, on this device. They are not uploaded to an OFCode notes server. Google Drive sync is a separate, optional choice.

By Ömer Faruk Bayrak / OFCode · Updated 24 October 2026

What does “local-first” mean here?

Your browser holds the working copy of your notes. Heldnote writes drafts locally as you type and keeps periodic versions. You can write without creating an account. Local saving does not need a Google connection.

Local-first describes where the working copy lives. It does not mean your browser can never lose data, and it does not mean the application is end-to-end encrypted.

Which browser can see my notes?

Browser storage is separated by origin: the combination of protocol, hostname and port. Notes on https://heldnote.app belong to that origin and this browser profile. Changing from the homepage to /app keeps the same origin and the same note database.

A different browser, profile, device or subdomain has a separate store. Notes do not automatically appear there. Use a JSON export/import or explicitly connect Drive sync to carry your library across.

What happens when I clear browsing data?

Clearing cookies and site data for Heldnote can erase the local database, including notes and their version history. A private window may discard its storage when the private session ends. A browser can also evict storage under pressure.

A saved note and a retained note are different facts. Heldnote’s status bar reports the local save state separately from the browser’s storage-retention state. Neither replaces a backup that you control.

How do I keep an independent copy?

  1. Open Export & import in the notepad sidebar.
  2. Choose the JSON export option and save the downloaded file somewhere you can find again.
  3. Keep an additional copy outside this device for important writing.
  4. To recover, use import as copies first. Replacing a library is a separate, destructive action with its own warning.

A JSON export contains readable note text and history. Treat it as a personal document: keep it in a location you trust.

What changes when I connect Google Drive?

Heldnote requests the narrow drive.appdata permission. It reads and writes a sync file in the app-specific part of your own Drive, rather than reading your other Drive documents. The transfer goes directly from your browser to Google.

Synchronization can carry edits and deletions between devices. It is useful for continuity, but an independent file export is still valuable. See history, sync and backup for the differences.

Does it work without the internet?

You can continue editing an already loaded page without a connection. Opening or reloading the website offline is not guaranteed because Heldnote currently has no service worker for offline loading. Drive sync waits for both a usable connection and a valid authorization token.

Who can read the local database?

Code running on the same website origin has access to its browser storage. This is why Heldnote does not load advertising or analytics scripts into the notepad. Optional Google authorization uses Google’s Identity Services library. See the privacy policy for the actual data flow.
