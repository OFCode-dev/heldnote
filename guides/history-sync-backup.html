A HELDNOTE FIELD GUIDE

Version history, sync and backup: three different jobs

Version history helps you revisit an edit. Sync brings changes to another device. A backup is a separate copy you can recover later. Heldnote offers all three, with different limits.

By Ömer Faruk Bayrak / OFCode · Updated 24 October 2026

Which one do I need?

ToolUseful whenImportant limit
Version historyYou want a paragraph you changed earlier.It lives with the note in browser storage and has retention limits.
Drive syncYou want to continue writing on another device.Changes, including deletions, can travel to other devices.
JSON backupYou need an independent copy of your library.It reflects the moment you exported it; later edits are not included.

How does version history work?

Heldnote saves drafts while you type and makes periodic committed snapshots. The history panel lets you preview a saved version before restoring it. Restoring a version preserves the current text as another version, so trying an earlier draft does not silently discard the text you replaced.

History is bounded. Recent versions are protected within retention rules, while older history may be pruned to stay within byte budgets. This is not an unlimited archive of every keystroke.

What does Google Drive sync do?

Each device pulls, merges and pushes an app-specific sync file. Renaming a note on one device and editing its text on another can merge as separate changes. If both devices change the same text, the losing text is preserved as a conflict version rather than silently thrown away.

Sync depends on Google’s availability, your connection and current authorization. Google’s browser access tokens expire, so you may need to click “Sync now” and choose an account again. Local saving continues independently.

Why is sync not an independent backup?

Synchronization is designed to move changes. If you delete a note and later purge it, that deletion can travel too. Keeping every device in agreement is a different goal from keeping an untouched copy of yesterday’s library.

Use sync for continuity, and an exported file for recovery. Keeping one does not make the other redundant.

How should I back up important writing?

  1. Export a JSON library before clearing browser data, replacing your library or changing devices.
  2. Keep the exported file outside the browser’s own storage.
  3. For important work, keep a copy away from the original device.
  4. Refresh the backup after meaningful changes, and check that you can find the file.

What should I do on a new device?

Open Heldnote in a modern browser and connect the same Google account if you use Drive sync. The sync cycle reads the remote library before a fresh device uploads its own state. If you use file backups instead, import the JSON as copies first and check the result before making destructive changes.

What can no browser notepad promise?

A browser can clear or evict site data, private sessions can end, devices can fail and a remote service can be unavailable. These limits are why Heldnote makes the storage state visible and includes export. The product is designed to reduce accidental text loss; permanent retention is not something a website can guarantee.
